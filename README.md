# Лесная Тишина — лендинг

Самостоятельный статический сайт без сборки и зависимостей.

**Запуск:** откройте `index.html` в браузере (двойной клик). Шрифт Manrope подключается неблокирующе — при отсутствии интернета используется системный шрифт.

## Что реализовано
- Светлый фон с голубым градиентом, стеклянные карточки (`backdrop-filter`), акцент `#0070BA` (взят из референса).
- H1 с анимацией подчёркивания, параллакс гор/леса/шале, плавный скролл.
- Появление блоков при скролле (`IntersectionObserver`), каскадные задержки, hover-анимации карточек и кнопок.
- Интерактивная 3D-сцена шале: наклон сцены курсором, «камера приближается» при скролле, всплывающие облачки-отзывы у шале №4 (переключаются вкладками и меткой на шале).
- Переключатель «Новогодняя»: мерцание гирлянд, больше снега на canvas, сохранение выбора в `localStorage`.
- Обратный отсчёт до 25.11 и модалка фиксации цены с валидацией, чекбоксом согласия на обработку данных и отправкой в Google Sheets (URL веб-приложения уже вставлен в `form.js`; настройка — в `GOOGLE_SHEETS_SETUP.md`).
- Фотогалерея из 6 кадров с лайтбоксом (клики, стрелки ←/→, закрытие по фону), фото заменили SVG-иллюстрации в hero, 3D-сцене и карточках решений.
- Полная адаптивность (3/2/1 колонка), мобильное меню, поддержка `prefers-reduced-motion`.

## Файлы
- `index.html` — структура и контент
- `assets/css/style.css` — стили и анимации
- `assets/js/main.js` — интерактив
- `styles.css`, `form.js` — стили и логика формы заявки
- `google-apps-script.gs` — скрипт приёма заявок в Google Таблицу
- `GOOGLE_SHEETS_SETUP.md` — инструкция по подключению; `AGENTS.md` — правила работы
- `assets/img/photo-01…06.webp|.jpg` — оптимизированные копии ваших JPG (1600 px по длинной стороне, webp + jpg-fallback).
- `assets/img/chalet.webp|.jpg` — оптимизированная копия `shale.jpeg`, используется в 3D-карточке шале и в галерее.
  Оригиналы лежат в корне и не используются сайтом.
