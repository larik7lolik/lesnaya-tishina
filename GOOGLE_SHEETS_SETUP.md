# Подключение заявок к Google Sheets

## 1. Таблица
1. Создайте Google Таблицу, например «Лесная Тишина — заявки».
2. В меню: **Расширения → Apps Script**.
3. Удалите стандартный код, вставьте содержимое `google-apps-script.gs`, сохраните.

## 2. Публикация скрипта
1. **Развернуть → Новое развёртывание → Веб-приложение**.
2. «Выполнить как» — **Я**.
3. «Кто имеет доступ» — **Любой пользователь / Anyone** (иначе браузер не сможет отправить заявку).
4. Нажмите «Развернуть», подтвердите доступ. Скопируйте **URL веб-приложения** (кончается на `/exec`).

## 3. URL в форме
URL уже вставлен в `form.js` (константа `SHEETS_ENDPOINT`) — менять ничего не нужно. Если нужно переопределить адрес, используйте один из способов:
- в `form.js` → константа `SHEETS_ENDPOINT = 'https://script.google.com/.../exec'`;
- либо в `index.html` → `<form id="hotelRequestForm" data-endpoint="https://script.google.com/.../exec">`.

`data-endpoint`, если заполнен, имеет приоритет.

## 4. Проверка
1. Откройте URL веб-приложения в браузере — должно появиться «Лесная Тишина — приём заявок активен».
2. Отправьте тестовую заявку с сайта. В таблице появится лист «Заявки» со столбцами: дата, имя, телефон, заезд, выезд, комментарий, согласие, источник, время отправки.
3. Без отмеченного чекбокса согласия форма заявку не отправит.

## Важное
- Сайт должен быть на хостинге с HTTPS. С `file://` внешние запросы могут блокироваться браузером.
- Запрос отправляется в режиме `no-cors`: Apps Script принимает данные, но браузер не видит код ответа. Поэтому после успешного `fetch` форма показывает сообщение об успехе; если сеть недоступна — показывается ошибка с телефоном.
- Первые строки таблицы создаются автоматически при первой заявке.
- Рекомендуется добавить в форму чекбокс согласия на обработку персональных данных и ссылку на политику (152-ФЗ) перед реальным сбором заявок.
- Заявки идут в таблицу без фильтра спама. При наплыве ботов добавьте скрытое поле-ловушку или капчу.
