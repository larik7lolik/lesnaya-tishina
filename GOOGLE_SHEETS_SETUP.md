# Подключение заявок к Google Sheets

## 1. Таблица
1. Создайте Google Таблицу, например «Лесная Тишина — заявки».
2. В меню: **Расширения → Apps Script**.
3. Удалите стандартный код, вставьте содержимое `google-apps-script.gs`, сохраните.

## 2. Публикация скрипта
1. **Развернуть → Новое развёртывание → Веб-приложение**.
2. «Выполнить как» — **Я**.
3. «Кто имеет доступ» — **Любой пользователь / Anyone** (иначе браузер не сможет отправить заявку).
4. Нажмите «Развернуть», подтвердите доступ. Скопируйте **URL веб-приложения** (кончается на `/exec`).

## 3. URL в форме
URL уже вставлен в `form.js` (константа `SHEETS_ENDPOINT`) — менять ничего не нужно. Если нужно переопределить адрес, используйте один из способов:
- в `form.js` → константа `SHEETS_ENDPOINT = 'https://script.google.com/.../exec'`;
- либо в `index.html` → `<form id="hotelRequestForm" data-endpoint="https://script.google.com/.../exec">`.

`data-endpoint`, если заполнен, имеет приоритет.

## 4. Проверка
1. Откройте URL веб-приложения в браузере — появится надпись «Лесная Тишина — приём заявок активен», адрес таблицы и имя листа. Это самый быстрый способ узнать, куда именно идут заявки.
2. Отправьте тестовую заявку с сайта. В таблице появится лист «Заявки» со столбцами: дата, имя, телефон, заезд, выезд, комментарий, согласие, источник, время отправки.
3. Без отмеченного чекбокса согласия форма заявку не отправит.

## Если заявка не появляется в таблице
1. Откройте URL веб-приложения в браузере и сверьте показанный адрес таблицы с той, которую смотрите. Чаще всего заявки есть, но в другой таблице или на другом листе.
2. Проверьте именно лист «Заявки» (не «Лист1»). Первые строки создаются автоматически при первой заявке.
3. Если вы меняли `google-apps-script.gs` после развёртывания, обновите код в редакторе и создайте **новую версию** в «Развернуть → Управление развёртываниями». Старый URL при этом сохраняется.
4. Форма теперь читает ответ Apps Script: если скрипт вернёт ошибку, вместо «Спасибо» появится сообщение с телефоном. Откройте консоль браузера — там будет адрес таблицы, в которую записана заявка.

## Если в столбце «Телефон» ошибка ячейки
Google Sheets воспринимает номер, начинающийся с `+`, как формулу и показывает `#ERROR!`. Скрипт хранит телефон только цифрами (`79991234567`) — такое значение не может быть формулой. Столбец C дополнительно имеет текстовый формат.

1. Замените код в редакторе Apps Script на содержимое `google-apps-script.gs` **целиком**, включая первые строки с константами. Если вставить только часть файла, появится `ReferenceError: SHEET_NAME is not defined`.
2. В «Развернуть → Управление развёртываниями» создайте новую версию — URL останется прежним.
3. Один раз запустите в редакторе функцию `fixPhoneColumn` (выберите её в списке функций и нажмите «Запустить») — она исправит уже записанные строки.
4. Откройте URL веб-приложения в браузере: в конце должна быть строка `Версия: 2026-11-22-digits`. Если её нет — развёрнута старая версия, создайте новую ещё раз. Пока форма отправляет телефон только цифрами (`79991234567`), старый скрипт тоже записывает его без ошибки; новая версия нужна для единообразия и диагностики.

## Важное
- Сайт должен быть на хостинге с HTTPS. С `file://` внешние запросы могут блокироваться браузером.
- Запрос отправляется обычным CORS-запросом с `Content-Type: text/plain`: Apps Script разрешает такой доступ, поэтому форма видит ответ и не показывает ложный успех.
- Первые строки таблицы создаются автоматически при первой заявке.
- Рекомендуется добавить в форму чекбокс согласия на обработку персональных данных и ссылку на политику (152-ФЗ) перед реальным сбором заявок.
- Заявки идут в таблицу без фильтра спама. При наплыве ботов добавьте скрытое поле-ловушку или капчу.
